## 关键设计决策

- **缺口分析语义**: 从"核心书目 vs 馆藏比对"改为"复本/热度缺口"（KG PageRank Top-N → heatRatio 判定）
- **确定性优先**: PriceRange 本地计算后覆盖 LLM 输出；ARIMA 奇异矩阵降级纯 AR
- **配置化**: 所有阈值/乘数/除数均为 `@ConfigurationProperties` 可调参
- **N+1 消除**: GapAnalysisService 批量 `selectBatchIds`；KgRelatedBookQueryService 批量加载图书+分类
