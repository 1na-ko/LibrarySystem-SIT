## 第一批：P1 重要问题（5 项）

### P1-01 GlobalExceptionHandler 补 `DataIntegrityViolationException` handler
- **文件**: `GlobalExceptionHandler.java` + `GlobalExceptionHandlerTest.java` + `pom.xml`
- **变更**: 新增 `@ExceptionHandler(DataIntegrityViolationException.class)` → 409；添加 `spring-tx` 依赖；新增单元测试
- **测试**: common 144 项全绿（+1）

### P1-04 OperationLogAspect 分层合规
- **文件**: `OperationLogAspect.java` + 新建 `OperationLogService.java`/`OperationLogServiceImpl.java`
- **变更**: AOP 改为注入 `OperationLogService` 替代直接注入 `OperationLogMapper`，消除跨模块 Mapper 调用
- **原则**: DIP（依赖倒置）——security 模块通过 Service 接口间接访问 core 模块数据层

### P1-07 GraphBuildServiceImpl N+1 写入批量化
- **文件**: `GraphBuildServiceImpl.java` + `Neo4jRepository.java`
- **变更**: 新增 `batchMergeNodes()`/`batchMergeRelationships()` UNWIND 批量方法；`writeToNeo4j()` 从 >30 次往返降至 7 次固定调用
- **原则**: DRY + Performance

### P1-08 EmbeddingServiceImpl 死代码清理
- **文件**: `EmbeddingServiceImpl.java`
- **变更**: 删除未使用的 `MAX_RETRIES` 常量（实际从 `embeddingConfig.getMaxRetries()` 读取）
- **原则**: YAGNI

### P1-15 fallbackNer 作者名分隔注释修正
- **文件**: `GraphBuildServiceImpl.java`
- **变更**: 注释从"按逗号/分号/空格"修正为"按逗号/分号/顿号；西方全名含空格整体保留"
