## 4. 关键架构决策

1. **ES 客户端**：手动声明 `ElasticsearchClient` Bean（使用 `elasticsearch-java` 8.11 + `JacksonJsonpMapper`），不引入 Spring Data ES Starter
2. **AdminBookController 模块归属**：置于 `library-security` 模块（而非 `library-core`），以使用 `@RequirePermission` AOP 注解，遵循 `AuthController` 的先例
3. **乐观锁**：修改操作改用 `updateById(entity)` + MyBatis-Plus 乐观锁插件，避免在 Controller 层构建 `LambdaUpdateWrapper`（提高可测试性）
4. **BizException 自定义消息受限**：`BizException(ErrorCode, Object...)` 使用 `String.format`，无法直接覆盖 ErrorCode 默认消息。冲突场景统一使用 `ErrorCode.CONFLICT` 无参构造
5. **相关图书降级**：KG 模块未就绪时使用 MySQL 同分类 + 同作者查询；阶段 7 后替换为 KG 多跳
6. **ES 最终一致性**：Spring Events + `@Async` + 3 次重试，延迟 < 1s
