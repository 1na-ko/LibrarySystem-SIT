## 架构决策

1. **树组装策略**：`CategoryService.getTree()` 采用一次全量查询 + Java 内存 `Map<parentId, List<VO>>` 组装（O(n) 遍历），不使用递归 SQL（避免 N+1 问题）。36 条种子数据（V2 迁移）已在 DB 中预置。
2. **VO 分层设计**：`BookSimpleVO`（精简视图）与 `BookDetailVO`（详情视图）分离——借阅列表/预约列表/搜索结果嵌套 `BookSimpleVO`，仅详情页使用 `BookDetailVO`，减少数据传输量。
3. **敏感数据保护**：`UserManageVO` 不含 `passwordHash`；邮箱脱敏（`z***@domain.com`）+ 手机脱敏（`138****1234`）在 Service 层完成。
4. **乐观锁**：`Book.version` 字段已就位，配合 MyBatis-Plus `OptimisticLockerInnerInterceptor`（Phase 0 已配置），Phase 3 编目编辑 + Phase 4 库存扣减可直接复用。
5. **AuthController 位于 security 模块**：延续 Phase 1 架构决策，认证控制器保留在 `library-security` 模块，`library-core` 仅承担领域业务 Controller。
