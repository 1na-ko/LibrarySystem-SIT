## 关键设计决策

- **依赖方向**: Port（端口）模式破除 core ← kg 循环依赖
- **GDS 降级**: 运行时探测 → PageRank 降级 Power Iteration、Dijkstra 降级 Cypher shortestPath
- **Cypher 安全**: 可变深度整数白名单校验后拼接，其余参数 bind；实体搜索 type 白名单防注入
- **事件驱动**: 监听 BookCreated/Updated/Deleted，AFTER_COMMIT 异步同步，3 次指数退避
