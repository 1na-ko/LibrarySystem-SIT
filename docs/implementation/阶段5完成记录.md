## 3. 关键设计决策

| 决策 | 理由 |
|------|------|
| 使用 WebClient + Jackson，不引入第三方 SDK | YAGNI — DeepSeek/DashScope API 结构简单，WebClient 足以胜任 |
| `LlmUnavailableException` 继承 `RuntimeException` | 基础设施故障 ≠ 业务规则违反；调用方自行降级 |
| `@ConditionalOnExpression` + `StringUtils.hasText()` | `@ConditionalOnProperty` 将空字符串视为"存在"，导致误创建 Bean |
| `NlpService` 无 `@ConditionalOn*` | HanLP 本地 JAR，始终可用，无网络依赖 |
| `EmbeddingService.embed()` 空文本返回零向量 | 下游批量处理时个别空文本不应阻断流程 |
| `onErrorMap` 在 `retryWhen` 之前 | IOException 先映射为 LlmUnavailableException，再进入重试队列 |
| `LlmConfig` 同时持 `@Value` 和 `@Bean` | 遵循 `ElasticsearchConfig` 项目已有模式 |
