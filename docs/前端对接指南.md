## 3. 认证流程

```http
POST /api/v1/auth/login
Content-Type: application/json

{ "username": "admin", "password": "Admin@123456" }
```

响应：
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
    "tokenType": "Bearer",
    "expiresIn": 7200,
    "user": { "id": "1", "username": "admin", "role": "ADMIN", ... }
  }
}
```

后续所有请求带头：
```
Authorization: Bearer <accessToken>
```

**Token 生命周期**：
- AccessToken：2 小时
- RefreshToken：7 天（轮换防重放）
- **登出后 AccessToken 立即失效**（user 维度 logout 黑名单，OWASP 最佳实践）
- 刷新：`POST /api/v1/auth/refresh` body `{ "refreshToken": "..." }`

**生产环境必改**（`application-prod.yml` 或环境变量）：
- `JWT_SECRET`：强随机密钥（≥32 字节）

- `CORS_ALLOWED_ORIGINS`：前端域名白名单

## 8. 关键约定（前端必读）

1. **Long → String**：所有 ID 字段（bookId/userId/borrowId 等）JSON 序列化为 String，前端用字符串接收，传参时也用字符串或数字均可（后端兼容）。
2. **`isDuplicate` 字段**：查重结果 `DuplicateCheckResultVO.isDuplicate` 已用 `@JsonProperty` 固定字段名，前端按 `isDuplicate` 解析。
3. **错误码**：`code != 200` 即业务异常，`message` 为中文错误描述；HTTP 状态码与业务 code 同步（401/403/404/409/503 等）。
4. **异步同步**：图书增删改后 ES/KG 同步经 RabbitMQ 异步（< 1s），前端创建图书后立即搜索可能短暂未命中，建议延迟 500ms 或刷新。
5. **限流**：登录/注册 20 次/分钟/IP，认证后 100 次/分钟/用户。前端遇 429 应提示并退避。
